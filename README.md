# My AtCoder Templates

AtCoderの競技プログラミングで使用する、Pythonのテンプレート・アルゴリズム・データ構造の実装を管理するリポジトリです。

## Files

| File | Description |
|---|---|
| [`temp.py`](./temp.py) | 基本テンプレート（import、定数、入力処理など） |
| [`SEG.py`](./SEG.py) | セグメント木・遅延セグメント木 |
| [`UF.py`](./UF.py) | UnionFind |

## Usage

各ファイルのコードを、必要に応じて自分の解答コードにコピーして使用します。

実装やテンプレートは、競技プログラミングで使いやすいように随時整理・更新します。

## Notes

- Pythonを使用します。
- 各実装の詳細は、それぞれのソースコードを参照してください。
- コードを利用する際は、必要に応じて参照元やライセンスを確認してください。
